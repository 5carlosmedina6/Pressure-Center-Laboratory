# Pressure-Center-Laboratory

## Description
This project uses MATLAB to analyze hydrostatic forces and the center of pressure on a plane surface under partially submerged and fully submerged conditions.

## Objectives
- Calculate experimental and theoretical moments.
- Determine resultant hydrostatic forces.
- Calculate the center of pressure.
- Compare results using tables and graphs.

## Tools
- MATLAB
- Hydrostatics Equations

## Results
The moment comparison graphs showed strong linear relationships between theoretical and experimental values, with R² = 0.9977 for the partially submerged condition and R² = 0.9998 for the fully submerged condition.
